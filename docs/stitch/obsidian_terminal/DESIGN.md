## Brand & Style

This design system embodies the ethos of the sovereign security engineer, systems programmer, and privacy maximalist. Merging high-utility vintage command-line ergonomics with cutting-edge defensive cybernetic clarity, it rejects bloated corporate web patterns in favor of purposeful, fast, monospaced architecture.

The visual style is **Cybernetic Terminal / Modernized Hacker Minimalist**. It is anchored by deep obsidian backgrounds, phosphor neon terminal greens, and hyper-legible cyan accents. The emotional response is one of uncompromising technical competence, absolute digital sovereignty, and nostalgic reverence for pure UNIX aesthetics. Structural borders, fine-pitch terminal frames, command prompt syntax cues (`>`, `~`, `root@`), and verification badges (PGP signatures, Onion mirrors, Mozilla Observatory A+ metrics) serve as both navigational guides and security provenance markers.

## Colors

The color palette centers around phosphor luminescence cut against void surfaces. In dark mode, `#0A0F12` provides an ultra-deep charcoal obsidian ground, preventing harsh OLED pitch-black eye fatigue while letting neon accents glow cleanly.

- **Primary (`#00FF66`):** Phosphor terminal green, reserved for primary prompts, active headings, terminal execution cues, and verified signatures.
- **Secondary (`#00D9B4`):** Electric teal, deployed for system meta-tags, subheadings, and secondary interactive link states.
- **Tertiary (`#00B0FF`):** Hyper-focused cyan, engineered for hyperlinked article entries, dotted underlines, interactive hovered items, and code highlights.
- **Neutral (`#0A0F12`):** Base terminal canvas. Layered surface tiers (`#0E1418`, `#1A262C`) articulate framed panels, prompt boxes, and verification drawers.

### Light Mode (Retro Parchment Terminal)
When toggled to light mode, the system translates into an amber-tinged continuous paper console (`#F4F1EA`). The primary text flips to high-contrast ink-black (`#121A1E`), while deep emerald (`#2FA53E`) and saturated cyan/marine (`#0084B4`) replace neon greens and cyans to ensure crisp WCAG AAA contrast ratios.

## Typography

Typography is strictly monospaced via **JetBrains Mono**, giving structural, character-by-character alignment reminiscent of VT100 terminals and contemporary IDE environments.

- **Headlines:** Set in bold weights with tight letter-spacing to prevent the wide monospaced gaps from disintegrating headline unity. Top-level titles incorporate CLI-style pipe cursors (`|`), leading prompt arrows (`>`), or command prefixes.
- **Body & Paragraphs:** Retain generous line-heights (1.7x) to optimize technical parsing and extended reading of architectural missives and post-mortems.
- **Metadata & Timestamps:** Always standardized into ISO 8601 formatting (`YYYY-MM-DD`) or bracketed military syntax (`[29 Jul 2026]`), set in `label-md` with `text-dim`.
- **Links & Dynamic Text:** Interactive links sport dashed or dotted bottom borders (`border-bottom: 1px dotted var(--cyber-cyan)`), shifting to solid luminescence upon focus/hover.

## Layout & Spacing

The layout is structured upon a **fixed-column constrained terminal chassis** that scales gracefully down to mobile screens. Max container width is fixed at `960px`, mimicking a widescreen terminal shell and preventing excessively long lines of code and prose.

- **Grid & Alignment:** Employs an explicit vertical rhythm built on a 4px/8px modular base. Elements lock to character column grids.
- **Breakpoints:**
  - *Mobile (< 640px):* Single column layout. Avatar moves above terminal bio. Log items stack timestamps below link titles. Margins reduce to `1rem`.
  - *Tablet (640px - 1024px):* 8-column layout. Hero card splits 5:3 between CLI bio text and portrait CRT frame.
  - *Desktop (> 1024px):* Centered fixed container (max 960px). Unobtrusive left terminal margin navigation or top monospaced bar with system indicators (uptime, PGP fingerprint, theme switch).
- **Scanning Line Matrix:** Background uses an optional faint 24px CSS grid overlay or subtle 2px scanline background texture with 0.03 opacity to reinforce hardware tactile feel without hampering contrast.

## Elevation & Depth

This design system avoids blurry consumer drop shadows, employing **crisp low-contrast outlines, phosphor glow halos, and stacked terminal window frames**.

- **Level 0 (Canvas Base):** Deep obsidian `#0A0F12` with faint scanline background.
- **Level 1 (Terminal Panels & Windows):** Surface tint `#0E1418` framed by a 1px solid border `#1A262C`. Panels can feature a subtle top header bar simulating an xterm / tmux pane.
- **Level 2 (Active Cards & Overlays):** Border brightens to `#00D9B4` at 40% opacity, paired with an ultra-soft perimeter glow: `box-shadow: 0 0 16px -2px rgba(0, 217, 180, 0.15)`.
- **Level 3 (Interactive Active / Terminal Focus):** Primary command elements and badges utilize an immediate phosphor aura: `0 0 8px rgba(0, 255, 102, 0.3)`.

## Shapes

The shape system leverages **Soft (0.25rem / 4px)** geometry. UI elements stay grounded in industrial precision. Completely round pill shapes are reserved exclusively for circular status indicators (e.g., active telemetry nodes, online pings) or avatar terminal vignettes.

All primary containers, dialogs, badges, and buttons utilize `rounded-sm` (4px) or sharp right angles, reflecting physical mainframe chassis, mechanical switch keys, and punch-card geometry.

## Components

### Buttons & Terminal Key Controls
- **Primary Action (Execute):** Enclosed in 1px border `#00FF66` with a faint `#00FF66`/10% background fill. Text is bold monospaced uppercase, prefixed with `> run` or `[Enter]`. Hover triggers an inverted state (`#00FF66` background with `#0A0F12` text) and a phosphor edge glow.
- **Secondary / Ghost Action:** 1px border `#1A262C`, muted text `#8A99A8`. Hover transforms the border to `#00F0FF` and text to `#00F0FF`.
- **Prompt Keyboard Keys (`<kbd>`):** Inset bevel simulation via 1px border `#2A3A42`, `#0E1418` fill, padded `2px 6px`, rendering shortcuts like `[Esc]`, `[Tab]`, or `[q]`.

### Verification Badges & Chips
- **Security Chips (PGP, Onion, Mozilla A+):** Compact rectangular badges with an icon/glyph on the left, a vertical 1px divider, and a verification status label on the right. 
- **Active State:** Border `#2FA53E`, text `#00FF66`, background `#0A1C12`. Features an inline green SVG lock or badge insignia.
- **Agent/Machine-Readable Badge:** Border `#1A262C`, text `#8A99A8`, highlighting markdown feeds (`/feed.md`), LLM indexability, and raw plaintext mirrors.

### Terminal Content Cards & Panels
- **Hero / Bio Panel:** Framed by a continuous 1px `#1A262C` or `#00D9B4` (at low opacity) outline with soft 8px corners. Contains an optional faux terminal title bar (`~ /home/sec-eng/adler`) with minimize/maximize ASCII icons (`[-] [x]`).
- **Log Lists (Index Feed):** Minimalist two-column tabular rows. Left column displays the hyperlinked entry title with a cyan dotted underline; right column renders right-aligned ISO timestamps (`YYYY-MM-DD`). Hovering a log row renders an arrow `->` prefix and illuminates both the text and date.

### Text Inputs & Search Command Bar
- **CLI Prompt Input:** Dark surface `#0E1418`, 1px border `#1A262C`. Always preceded by an uneditable prompt anchor: `root@box:~$`. Caret is a solid blinking block cursor (`background: #00FF66`, animation: 1s steps(2, start) infinite).

### Selection Controls (Checkboxes & Radios)
- **Checkboxes:** Monospaced ASCII-styled boxes `[ ]` and `[x]`, or square 14px boxes with a 1px border and a neon green centered tick mark.
- **Radios:** Circular `( )` and `(*)`, featuring a glowing center emerald node when selected.
