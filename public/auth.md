# adlermedrado.com.br auth.md

This site exposes public, read-only content to people and agents.

## Agent access

- Registration is not required or available.
- Authentication and credentials are not required.
- There are no protected API scopes.
- Agents may read the content API, Markdown page representations, feeds,
  discovery metadata, and public pages anonymously.

The site does not currently operate an OAuth authorization server, an OpenID
Provider, or a protected resource API. OAuth discovery metadata will be
published if a protected API is introduced.
